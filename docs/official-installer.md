# QM1 官方安装器方案

交付物是基于通过签名验证的 Debian netinst ISO 改造的完整安装盘，名称为 `qm1-debian-installer-amd64.iso`。它启动 Debian-Installer，不启动预部署系统的登录界面。

## 安装界面与目标盘

引导菜单默认选择官方 `Install` 文字安装。图形安装、专家安装、救援模式和返回 UEFI 设置的入口保留。正常流程是语言和键盘、网络、账号、磁盘分区、安装软件、安装 EFI 引导器、完成安装。

公共 ISO 保留账号设置界面。本机私人版本可以通过 `personalize-official-installer.py` 注入指定账号的密码哈希；root 直接登录关闭，管理员操作使用该账号的 `sudo`。私人版本仍要求选择磁盘和确认分区写入，不预设擦除某块设备。

安装目标应按容量和型号识别为 QM1 内部 eMMC，不能仅依赖 `/dev/mmcblkN` 编号。安装 U 盘不是目标盘。完成后移除 U 盘，验证从 eMMC 冷启动；EFI 同时应具有对应固件架构的可移动介质回退入口。

## 对官方介质的改动

- 保留官方安装内核、安装器、软件包目录、菜单与混合 BIOS/UEFI 引导结构。
- 增补同一官方 GRUB 包提供的完整 IA32 CD loader 和配套模块；原 x64 loader 保留。
- 默认使用固件文字输出，并把 i915 原生显示驱动加入安装环境，避免只依赖固件 GOP。
- 安装环境及目标系统使用匹配官方内核 ABI、包版本和符号 CRC 的 RTL8723BS 驱动；加入对应 Wi-Fi、蓝牙固件及板级依赖。
- 目标系统的板级设置以 Debian 软件包安装，包括 eMMC 电源、Bay Trail idle、音频、蓝牙和内存管理。账号和分区由 Debian-Installer 管理。
- 提供板级软件包的本地依赖仓库。网络凭据、密码哈希和个人 SSH 公钥只允许在本机私人介质中加入。
- 不预装 Hermes 或 Chrome。

## 发布门槛

CI 必须验证上游签名和 SHA512、驱动符号 CRC、更新后的 EFI FAT 与 USB 分区/El Torito 指向一致，并在 IA32、x64 UEFI 下完成安装、拔除虚拟 USB、从目标盘启动、实际密码登录、sudo 和驱动模块加载。自动分区的公开测试凭据只存在于临时测试 ISO，不能进入交付 ISO。

这些检查不能替代 QM1 实机验收。真正的 Wi-Fi 关联与传输、蓝牙、插卡后的 microSD、eMMC 长稳、HDMI 显示/音频，以及 Hermes + Chrome 的组合负载，必须分别记录实机结果。未完成的项目不能记为通过。
